# 实习中记录

> 日常积累的原始素材，是后期总结和复盘的基础。

## 目录说明

| 目录 | 用途 | 频率 |
|------|------|------|
| [daily-logs/](daily-logs/) | 日报，记录每天的工作内容和收获 | 每天 |
| [weekly-reviews/](weekly-reviews/) | 周报，每周深度复盘 | 每周 |
| [projects/](projects/) | 项目文档，每个参与项目的完整归档 | 按项目 |
| [notes/](notes/) | 零散笔记、会议记录、临时想法 | 按需 |

## 使用建议

1. **日报不过夜** — 下班前花 5 分钟填完，防止遗忘
2. **周报在周五下午** — 趁记忆新鲜时完成深度复盘
3. **项目文档随项目推进** — 不要等项目结束再补，很多细节会丢失
4. **笔记随手记** — 不用追求格式，先记录下来，整理是后面的事
