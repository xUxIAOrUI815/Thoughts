# 实习后总结

> 实习结束后的系统性复盘，将碎片化的日常记录提炼为结构化的成长输出。

## 产出物

- [**summary.md**](summary.md) — 实习整体总结：做了什么、学到了什么、产出了什么
- [**reflection.md**](reflection.md) — 个人反思：优势和不足、职业规划校准、对 Agent 研发的理解变化

## 使用时机

建议在实习最后一周开始动笔，利用之前的日报/周报/项目文档作为原始素材，避免凭记忆硬写。

## 写作建议

1. **用数据说话** — 尽量用量化指标描述成果（上线功能数、性能提升比例、覆盖用户数等）
2. **STAR 法则** — 描述关键经历时，交代 Situation → Task → Action → Result
3. **诚实面对不足** — 复盘的价值在于发现盲区，不只是展示亮点
4. **记录人际关系** — 那些帮助过你的 mentor 和同事，保持长期联系
